# Ormyn v1.0.0

Place `Ormyn.exe` in this folder (tracked with Git LFS) and keep `SHA256SUMS.txt` next to it.
Quickest way: run `tools\stage-release.bat` from the repo root; it builds the exe here and writes the checksum.

**Requires:** Windows 10 (2004) or newer and the .NET 8 Desktop Runtime.

## Included in 1.0.0
- Dynamic Island overlay that docks flat into the top edge; reveals on startup, on the hour and half hour (clock),
  when a song starts, on alerts, and when the cursor touches the top-middle of the screen.
- Spotify and YouTube Music via the Windows media session: album art, song-coloured pill, bloom, equaliser,
  and a full-width backlight along the top edge while a song plays.
- Alerts: volume, brightness, clipboard, battery, notifications (app icon, click opens the app), calls, timers.
- Tabs: Music, Timer (pomodoro / timer / stopwatch), Audio (mic and per-app mute + volume dial), System (CPU, memory, network, battery).
- Automatic Do Not Disturb while a game is running; tray menu; start with Windows; short eyes-open startup animation.
